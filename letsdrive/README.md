# Letsdrive assets

Drop the three phone screenshots here (they appear automatically on `/work/letsdrive`):

- `ride.png` — carpooling / find-a-ride screen
- `rent.png` — car-rental screen
- `chat.png` — real-time chat screen

Recommended: tall phone aspect (~9:19), e.g. 1080×2280 PNG. Until a file exists, the slot
shows a clearly-marked placeholder; the screenshot covers it the moment you add the file.

**Demo recording:** paste the screen-recording link into `demoUrl` in
`src/data/letsdrive.ts` to activate the "Watch demo" button.

(Repos stay private — the page only ever shows screenshots + description.)
