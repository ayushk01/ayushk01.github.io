Freelance client project · 2024–2025

Letsdrive

Share a ride on a route you're already driving — or rent out your car when it's sitting idle. Two marketplaces in one app.

ROLE
Sole engineer — all three tiers
TIMELINE
2024–2025 · solo
SCOPE
Mobile · Backend · Admin

What I built

01 · Mobile app

Flutter · GetX

Modular architecture with live Google Maps routing, Stripe payments, Firebase auth & push, real-time chat over Socket.io, and driver & owner earnings.

Flutter GetX Dart Google Maps Stripe Firebase Socket.io

02 · Backend API

TypeScript · Express · Prisma

A 13-model PostgreSQL schema spanning carpooling and car rentals across 30+ migrations — Socket.io chat, Google Maps services, AWS S3 uploads, JWT auth, rate-limiting & security middleware, and structured logging.

TypeScript Express Prisma PostgreSQL Socket.io AWS S3 JWT

03 · Admin dashboard

Next.js · TypeScript

A NextAuth-secured dashboard managing users, trips, vehicles and rentals — TanStack data tables and Recharts analytics, styled with Tailwind and Radix.

Next.js TypeScript Tailwind Radix TanStack Recharts NextAuth

Engineering highlights

  • 13-table schema modeling two marketplaces in one system (30+ migrations).
  • Real-time chat & live trip tracking with Socket.io + Google Maps.
  • Stripe payments with driver/owner payouts on both sides.
  • Three codebases — mobile, backend, admin — shipped solo over two years.
