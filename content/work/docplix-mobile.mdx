## The product

DocPlix ships two mobile apps:

- **Patient app** — for patients to book appointments, see prescriptions, and message their clinic. [App Store · APP_STORE_URL_PATIENT] · [Play Store · PLAY_STORE_URL_PATIENT]
- **Clinician app** — for clinicians on the go: view today's appointments, check patient history, write quick notes. [App Store · APP_STORE_URL_CLINICIAN] · [Play Store · PLAY_STORE_URL_CLINICIAN]

Both are built in React Native, sharing the bulk of the codebase with our web app's data layer and types.

## Tech notes

- **Stack:** React Native, TypeScript, React Navigation, Reanimated, Zustand for local state, React Query for remote.
- **Hermes** as the JS engine on both platforms.
- **Push:** APNs + FCM via a single backend service.
- **Release engineering:** GitHub Actions for builds; Fastlane for signing and store uploads.
